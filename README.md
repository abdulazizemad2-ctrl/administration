# محاكي القرارات الإدارية

اختبار محاكٍ لمقرر القرارات والعقود الإدارية (القسم الأول: القرارات الإدارية)، بقسمين:

- **اختيار من متعدد:** 30 سؤالاً تُسحب من بنك فيه 53 سؤالاً، وتُصحح آلياً مع شرح كل إجابة.
- **مقالي:** 6 أسئلة، منها حالتان عمليتان، ويُقيَّم كل سؤال ذاتياً وفق عناصر الإجابة النموذجية.

الموقع ملف واحد هو `index.html`، ولا يحتاج إلى أي تثبيت. تُحفظ المحاولة في متصفح المستخدم.
